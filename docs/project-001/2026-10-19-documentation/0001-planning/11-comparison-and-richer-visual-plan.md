## Plan review and failure handling

- Fairness: fixed equal internal viewports; named original commit; no comparison to the wrong earlier draft. Different section lengths use deliberate matched jumps rather than misleading scroll synchronization.
- Browser boundaries: same-origin review serving through Vite's public API. No cross-origin DOM assumptions, security disabling, duplicate public deployment or proxy rewriting of original routes.
- Source protection: review files and selected image masters stay outside the imported Git root; original route/source behavior is not patched. Preview build has no production release stage.
- Accessibility: labels, visible selected states, keyboard actions, native detail dialogs with focus return, normal page scrolling, dynamic reduced-motion handling and a single new-design motion control in the viewer. Actual-site continuous decorative motion would use one quiet shared footer Motion toggle rather than scattered Pause buttons.
- Animation ownership: entry, ambient and hover use separate nested layers or separate transform properties. A hover cannot overwrite an assembly transform. Pausing retains elapsed progress; replay cancels prior work before starting. Static/failed assets never prevent reading or navigation.
- Concurrency: rapid image/category changes use a request/version token; stale decode callbacks cannot replace the current selection. Keep the last valid image and exact frame size while loading. If no valid image exists, show the native motif and an honest retry.
- Performance: lazy-load below-fold imagery, reserve dimensions, keep exactly one eligible opening accent and no service/step loop; pause when hidden/offscreen/reduced. No per-frame React rerender or WebGL background for this brief.
- Customer operations: do not repair simulated booking/payment/messages under a visual-comparison approval. No invented reviews, scores, availability, qualifications or prices. The separately diagnosed operational gaps remain visible in documentation.
- Recovery: original and first study remain intact. Generated masters and optimized derivatives have a manifest. Failed generation is recorded and retried/adjusted within the selected brief; no unrelated stock-room fallback.
