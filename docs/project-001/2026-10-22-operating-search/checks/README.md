# Captured local verification helpers

These are the actual test-only helpers used for the22 October clinic page checks. They are not application routes, production dependencies or a second booking implementation. All browser writes are intercepted/local, external providers are blocked, and synthetic fixture identities must never be interpreted as real patient data. The original full counter pools, failed runs and screenshots are retained in the factory workspace QA directory; the current handoff keeps lean source-bound summaries.

Use the application clone as CLINIC_SOURCE_ROOT and provide test-only Node modules through CLINIC_COVERAGE_NODE_MODULES / BOOKING_BROWSER_NODE_MODULES plus a locally installed Chromium through BOOKING_CHROME_EXECUTABLE. The captured WSL paths in a few wrappers identify the exact original environment; adapt those paths to the installed local tools before reuse. Do not add test tools or instrumentation to the production bundle. The installed booking package owns its own independent complete checks/dependency locks.

The source walker baselines every working app/build owner before instrumentation. The join verifies unchanged file hashes, exact original statement/function/branch maps and safe integer counts. It combines observed hit status rather than adding cumulative snapshots as if they were independent runs. Utility refinements caused two owner changes: old pools were preserved, native/browser pools recollected, and only hash-unchanged UI lifecycle modules retained. No working owner is excluded. A source change requires a new baseline and proof; never edit a counter, weaken an assertion or carry stale changed-owner hits.

The loopback generated-page server only handles GET/HEAD and cannot proxy a real API. Standard public-page readback helpers permit only the four approved public domains and never submit a form/payment. The API-entry contract substitutes only its composition dependency and proves declared argument wiring/refusal; complete actual engine behavior is covered by the separate sealed-package qualification.

Natural-scroll screenshots, source counters, no-JavaScript/automated accessibility checks, supported motion-timeline control checks, production compilation/export and actual hosted observations remain separate receipts. Do not treat scrubbing a motion timeline or a synthetic callback as real visual/provider acceptance.
